# Simple Calculator with Replay System

## Summary
This is a simple command-line calculator written in Python. It performs basic arithmetic operations: addition, subtraction, multiplication, and division. The final project improvement adds a replay/history system, allowing users to view previous calculations in a numbered list.

## Project Goals / Objectives
- Expand the midterm calculator by adding a history/replay system.
- Keep code clear, beginner-friendly, and Pythonic.
- Use only standard Python 3.
- 

## Features
- Basic arithmetic operations (+, -, *, /)
- Input validation to prevent invalid numbers or operators
- History/replay system to view past calculations
- Menu-based user interaction

## How to Run
Make sure Python 3 is installed on your system.
